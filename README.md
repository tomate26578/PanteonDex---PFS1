# PanteonDex---PFS1
PanteonDex es una enciclopedia visual de panteones inspirada en Hollow Knight. La experiencia está pensada como un archivo ceremonial de la Casa de Dioses: cada cámara presenta su propio dominio, dificultad, atmósfera y lista de rivales. El nombre esta inspirado en las Pokedex de la serie y videojuegos de Pokémon
